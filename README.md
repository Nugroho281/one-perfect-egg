An entry for the [make.fun](https://make.fun/bounty/the-picture-that-tastes-of-one-20261122-2047) bounty **"The picture that tastes of one ingredient"**.

## The picture

One perfect soft-boiled egg. Its shell is cracked open at the top and the
molten golden yolk spills out, glistening, onto dark slate — a single
ingredient, shot like a jewel. Warm dramatic light, deep shadows, the egg
large and centered so it still reads delicious at 300 pixels across.

## How it works

`main.py` (pure Python standard library, no third-party packages) writes
the picture to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`).
The 1024×1024 PNG is embedded in the program as base64, so it runs in a
sandbox with no network. Output: 1,007,984 bytes, within the 1 MiB cap.

```sh
python3 main.py
```
